## Findings not yet planned

- Evaluate page lot rule: a chipset word in a lot title ("Lot of 2 i7-4790K SR219 Z97") counts as a board, so `/evaluate` prices one CPU while the CPU search prices the lot. Possible fix: `find_part(p, title, allow_chipset=False)` in the `cpu_only` check (scanner.py), untested.
- Evaluate page Buy/Check stamp ignores rows the user adds or edits. What a hand-typed value means for confidence is the owner's call (see plan 009).
- Direction options from the audit, not selected yet: an Inspect link from scanner cards to `/evaluate`, a GPU-only search, price data age shown on the page, price data for coolers, PSUs, storage and cases.

## Findings considered and rejected

- SSRF through the evaluate link field: only a 9-15 digit item number reaches a fixed eBay URL.
- Missing eBay selling fees: `config.py` records that the owner resells locally.
- eBay keys in git history: always read from the environment.
- MySQL root/root password in history: already in TO-DO, and the MySQL code is gone.
- Linear `byKey` lookup in `main.js`: at most ~150 items.
- Known extractor limits already listed in TO-DO.
